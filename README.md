# MFL Finance public pages

Pagine pubbliche per la registrazione dell'applicazione personale MFL Finance.

## Pubblicazione
1. Crea il repository pubblico `mfl-finance` nell'account `mflametti`.
2. Carica nella root `index.html`, `privacy.html`, `terms.html`, `style.css`.
3. Commit su `main`.
4. Settings > Pages > Deploy from a branch > `main` / `(root)`.
5. Attendi la pubblicazione e verifica i tre URL.

Non caricare mai chiavi `.pem`, token, CSV, estratti conto, database o backup.
